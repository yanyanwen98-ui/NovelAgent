# 小梨儿（孩子，暂定名）

> 作者定「暂定，得让孩子家长起」——孩子由黎舟舟与陆星满共同抚养，称呼习惯随抚养环境定；出卷纲前作者可随时改（备选：梨芽、小满、星梨）。

## 基本信息
- 姓名：小梨儿（暂定）
- 性别：暂不定（出卷纲前作者拍；默认「小」字辈、男女皆可用的中性名）
- 角色定位：双男主感情线的「孩子」；全书治愈线的核心资产，结局「人间一家」的收梢点
- 身份标签：梨子化形（黎舟舟结的梨子，经多年孕育化形）→ 三四岁孩童 → 两姓之子的唯一凭证
- 年龄起点：化形时三四岁（全书 2 卷末或 3 卷初出场）
- 外貌特征：小圆脸、奶乎乎，头发里天生一缕浅青（树妖底子），笑起两颗小虎牙，跑起来像一颗滚圆的梨子
- 性格关键词：黏大人、聪明到不像三四岁（灵智底子）、怕雷（梨子怕打雷，设定梗）
- 与两位父亲的关系：
  - 黎舟舟＝「结他的那个人」（生父位）：化形前多年是黎舟舟用神魂一点点养大的
  - 陆星满＝「养大他的人」（养父位）：死遁前，黎舟舟走时的假象是「临终托付」，孩子跟着陆星满
  - 叙事功能：孩子对两位父亲的反应（只黏哪个、认哪个）是火葬场阶段读者情感投射的载体
- 体质（关键设定）：黎家梨血脉＋陆星满神魂温养——**不是唐僧肉**（被神魂「洗」过，无炼化价值），这是死遁能保住孩子的前提；也是「两人合养」铁证的唯一凭证
- 退场方式：不退场，是结局人物；中后段是「护住他」的主线压力源（利益链盯上黎舟舟，孩子就是最大的软肋与筹码）

## 出场与转变节点
- 第 2 卷末/第 3 卷初：梨子熟透坠地，化形为小梨儿（全书最有仪式感的一章）
- 第 3 卷末：黎舟舟死遁，孩子被「托付」给陆星满
- 第 4-5 卷：孩子成了「找人的信物」（陆星满带着他满世界走＝带着「黎舟舟的遗物」走，读者知道，攻不知道——信息差糖点）
- 结局：人间一家，各地安家

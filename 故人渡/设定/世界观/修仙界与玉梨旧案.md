# 世界观：修仙界与黎舟舟旧案

## 力量体系（修仙者）
- 境界（由低到高）：练气 → 筑基 → 金丹 → 元婴 → 化神 → 合道 → 大乘
  - 注：本书主角不走战力升级线，境界只作背景刻度；陆星满的神魂修为封顶＝前世散尽前的境界（合道），明示后不再突破
- 特殊体系：神魂独立于肉身——神魂可寄体、温养、渡魂（全书机制基石：陆星满「神魂护苗千年」与今世「痴儿肉身」都靠它成立）
- 妖植体系：妖植可化形，化形条件=神性与灵质积累；黎家梨族天生神性极高，故「炼化食用可大幅增境」——这是利益链存在的原因

## 社会结构
- 宗门：大6小9（大6为利益链主干，中反派出自其中）
- 散修：边缘群体，「补物」黑市多由散修跑线
- 凡俗：修仙界与凡间分界，结局「不管修仙界纷扰」的落点在凡间各地（人间烟火=治愈线舞台）

## 黎家梨族旧案（主线谜团，分层揭示）
- 千年前：黎家梨族供「天地灵材」于各宗，某大宗门主导的「炼体大补方」需要黎家梨族为引——屠族灭口，对外宣称「黎家梨族妖化反噬、自行而灭」
- 黎舟舟是孤株遗孤，藏于深山，攻（前世）发现并救之
- 旧案卷宗被宗门封存：黎舟舟死遁后，陆星满翻案=撞宗门利益（3-4卷主矛盾）
- 真相三层：①屠族是利益链主动灭口（3卷）②攻受自爆与养苗细节（4卷）③「炼化惯例」实为规则层面被利益链塑形的「天道借口」，破了惯例即终局（5卷）

## 小梨儿（孩子，暂定）设定
- 受与攻结合所结的梨子，熟透坠地，历经多年（千年尺度）孕育化形为三四岁孩童「梨子」
- 体质：黎家梨族血脉+陆星满神魂温养——既不是唐僧肉（体质被神魂「洗」过了），又是两姓之子的唯一凭证
- 叙事功能：死遁的护点（受走是为了护他和攻）、寻人线的信物（攻带着梨子=带着「黎舟舟的遗物」满世界走）、结局收梢（人间一家的核心）

## 文风基调
- 修仙界：清冷、利益链明暗交织、旧案有重量
- 今世情感线：宿命感+烟火气，甜是实的（CP行为要具体，不要工业糖精）
- 火葬场段：攻的执念=读者补偿点，虐受不虐读者
- 结局：降维到凡间，节奏放慢，梨花、梨子、各地行脚，「不管修仙界纷扰」

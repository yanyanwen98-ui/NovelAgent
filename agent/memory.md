# Memory Architecture

## Canon
Locked facts and rules.

## World
Geography, history, factions, supernatural rules, resources, terminology.

## Characters
Profiles plus evolving state.

## Story
Premise, main plot, subplots, arcs, unresolved threads.

## Foreshadowing
Track introduction, meaning, status, payoff window, importance, and related entities.

## Timeline
World chronology and chapter chronology.

## Current state
What matters immediately now.

## Chapter records
Eventually store prose, summary, facts, character changes, timeline events, plot-thread changes, and foreshadowing changes.

## Principle
Store facts and state separately from raw prose. Use exact structured retrieval for facts and semantic retrieval later when useful.

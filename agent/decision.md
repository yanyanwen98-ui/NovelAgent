# Decision System

## GREEN
Autonomous: names, ordinary scenes, minor characters, routine dialogue, local transitions.

## YELLOW
Autonomous but reversible: moderate subplot changes, local restructuring, minor character fate changes.

## RED
Author approval required: premise, ending, core world rules, protagonist identity/goal, major relationship changes, broad retcons, genre/audience/tone changes.

A RED decision must store:
- id
- question
- options
- selected option
- rationale
- affected memories
- timestamp

The agent resumes from saved state after approval.
